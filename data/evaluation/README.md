# Evaluation Datasets and Benchmark Suite

Contains benchmark queries and test scenarios for comparing:
1. Baseline System: Single model performing the entire request without orchestration.
2. Proposed System: Agentic router with multi-model capability routing and verified tool grounding.

Evaluation metrics recorded:
- Task completion rate
- Output schema validity
- Evidence support ratio
- Routing compatibility
- Latency (average and p95)
- Estimated cost per request
- Fallback recovery rate
